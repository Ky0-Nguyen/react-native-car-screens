# Changelog

## 0.1.0

First release.

- `information`, `list` and `tabs` templates plus alerts, on CarPlay and Android Auto.
- In-place updates by template id; latest state kept natively for late car connections.
- Events: connect, disconnect, action, select, pop, alertAction, alertDismissed.
- React Native CLI support (TurboModule, phone scene delegate) and an Expo config plugin.
